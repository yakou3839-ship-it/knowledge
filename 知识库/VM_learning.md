# 一、什么是虚拟机（通俗版）
**虚拟机（VM）**：在你现有的电脑系统（真机）里，用软件虚拟出一台独立、全新的“虚拟电脑”。
简单理解：一台物理电脑，同时跑多套互不干扰的操作系统，它们共用硬件资源，但互相隔离。

举个例子：
你电脑是 Windows 11，装虚拟机软件后，可以再虚拟一台 Windows7、Linux、安卓，这些系统就像单独一台电脑，窗口化运行在本机。

## 两种常见虚拟机
1. **系统虚拟机（最常用，新手接触）**
完整模拟一台电脑，能装完整操作系统：VMware Workstation、VirtualBox
2. **容器虚拟机（Docker，进阶）**
轻量化，不完整模拟硬件，只隔离程序，新手先不用管。

# 二、虚拟机有什么作用
## 1. 安全测试，不怕电脑中毒
- 测试来路不明软件、破解工具、外挂、病毒样本
- 病毒只会破坏虚拟机，关闭重置后一切恢复，主机系统完全安全
## 2. 多系统随意切换
- Windows 用户体验 Linux（Ubuntu、CentOS）学习编程、服务器
- 新软件只支持 Win7/XP，本机是 Win10/11，虚拟机完美兼容
- 苹果电脑装 Windows 打游戏、办公
## 3. 学习编程、服务器、运维
程序员/网工必备：搭建本地服务器、网站环境、测试代码，不用买额外电脑
## 4. 软件环境隔离
不同软件依赖冲突，分开装在不同虚拟机，互不干扰
## 5. 怀旧、老程序运行
老旧单机游戏、老式行业软件，新系统无法兼容，虚拟机完美运行
## 6. 低成本多设备开发
一台电脑同时开多台虚拟主机，模拟多台服务器组网做实验

# 三、新手推荐工具（免费优先）
1. **VirtualBox**：完全免费开源，轻量，低配电脑也能跑，新手首选
2. **VMware Workstation Player**：个人免费，性能更强，兼容性更好，功能更全
> 硬件要求：内存至少8G，推荐16G；硬盘预留50G以上空间；CPU支持虚拟化（绝大多数近几年电脑都支持）

# 四、新手从零熟练使用完整步骤
## 第一步：开启电脑CPU虚拟化（必须做，否则虚拟机巨卡）（没有用过）
1. 重启电脑，开机时按快捷键进BIOS：
   - 联想/华硕台式：Del
   - 笔记本：F2、F10、F12
2. 在BIOS找到：
   Intel CPU：`Intel Virtualization Technology (VT-x)`
   AMD CPU：`SVM Mode`
3. 设置为 Enabled（开启），保存重启。

## 第二步：安装虚拟机软件 + 下载系统镜像
1. 官网下载 VirtualBox / VMware，一路默认安装
   -  过程中有个enable keyboard，猜测是和鼠标/键盘移动有关

1. 下载系统镜像（.iso 文件）：
   - 新手学习：Ubuntu（最简单Linux）、Win10纯净版
   - 办公兼容：Windows7
   - 注意：每个系统的root（主用户）文件夹不同，且用户权限也不同

## 第三步：新建第一台虚拟机（标准流程）
1. 点击「新建虚拟机」，自定义名称、选择系统类型
2. 分配内存：真机8G内存最多分给虚拟机3G；16G可分6-8G，**不能超过本机一半**
   - 这个内存指的是运行内存（基带RAM）
3. 网络类型：桥接、NAT、仅主机与不使用网络（以后都默认选择桥接，可以直接连接上网，并且可以查看ip）
   -  桥接：
     - 原理：虚拟机藏在主机背后，共用你电脑的 IP 上网
     - 优点：开箱即用，不用额外配置；家里路由器不会多占一个 IP；虚拟机可以正常上网、下载、浏览网页；主机和虚拟机之间能互相传文件访问。
     - 缺点：**外面局域网里的手机、其他电脑无法主动访问你的虚拟机**
     - 适用场景：日常上网、学习系统、测试软件、普通 Linux 练习（90% 新手都用这个）
     - 这里会有一个问题：无法通过ip a获取虚拟机ip地址
       - 有pdf解决文档，测试可行
   - NAT：
     - 原理：虚拟机和你电脑、手机、平板一样，是局域网里一台独立设备，路由器单独分配一个 IP
     - 优点：同 WiFi 下所有设备都能访问虚拟机（适合搭网站、本地服务器、多设备联调）
     - 缺点：家里设备多会占用路由 IP；测试病毒、恶意程序时，风险会扩散到整个局域网设备
     - 适用场景：搭建本地网站、服务器、多台虚拟机互相组网、需要手机访问虚拟机项目
   - 仅主机：
     - 原理：只在**虚拟机 ↔ 你的电脑**之间连通，完全上不了互联网
     - 优点：完全隔离外网，安全；适合纯本地离线实验
     - 缺点：虚拟机无法上网下载软件
     - 适用场景：离线病毒测试、纯本地内网实验、完全不想联网的环境
   - 不使用网络：
     - 虚拟机彻底断网，没有任何网卡，完全隔绝所有网络，极少使用。
4. 创建虚拟硬盘：推荐动态分配（占用多少存多少，省空间），大小建议30G以上 
   - 虚拟硬盘后缀为.vmdk存放在你创建虚拟机时的地址
5. 挂载下载好的ISO镜像，启动虚拟机，像给新电脑一样安装系统

## 第四步：安装增强工具（关键，解决卡顿、分辨率、文件互传）
虚拟机装好系统后，一定要装：
- VirtualBox：增强功能（Guest Additions）

- VMware：VMware Tools

  - 直接通过虚拟机上VM标签下的tools安装不上
  - 最后用的是直接在终端将工具包下载（成功）

  作用：

- 鼠标自由进出虚拟机窗口，不用按快捷键切换

- 自动适配全屏分辨率

- 主机和虚拟机互相拖拽文件、共享文件夹、复制粘贴文字

## 第五步：新手必学核心操作
1. **快照（最重要功能）**
相当于给虚拟机备份存档，安装危险软件前拍快照，出问题一键恢复干净系统。
2. **共享文件夹**
主机和虚拟机互通文件，不用U盘来回拷贝。
3. **虚拟机网络设置**
- NAT（默认）：虚拟机可以上网，外部无法访问虚拟机，日常使用
- 桥接模式：虚拟机和本机连同一个局域网，适合搭建服务器、组网实验
4. 开关机、暂停、重置、删除虚拟机
    不要直接删硬盘文件，软件内正常删除，避免残留垃圾。

5. **通过一些shell工具在外部链接虚拟机**

  - finalshell（测试成功）

    左上角点击新建连接直接按照提示填写

  - xshell（需要买，可以试用30天）（测试成功）

    左上角

  - 电脑自带shell（power shell、cmd）(测试成功)

    `ssh 虚拟机名@虚拟机地址`

# 五、新手快速熟练的练习路线（循序渐进）

## 阶段1：基础操作（1天掌握）
1. 成功安装一台Windows虚拟机，学会快照、共享文件夹、复制粘贴
2. 切换全屏/窗口模式，调整内存硬盘参数
3. 切换NAT/桥接两种网络，测试虚拟机上网

## 阶段2：Linux入门（3~7天）
安装Ubuntu虚拟机，练习基础命令：文件操作、软件安装，体验Linux系统，编程、服务器基础环境。

## 阶段3：实操用途练习
1. 在虚拟机安装破解软件、小工具，测试安全性，观察快照还原效果
2. 搭建本地网站环境（宝塔、PHP），模拟服务器开发
3. 多开两台虚拟机，互相ping通，简单组网实验

# 六、新手常见避坑提醒
1. 内存分配过高：本机8G内存分给4G以上，主机直接卡顿
2. 忘记开CPU虚拟化：虚拟机运行极其卡顿
3. 不装增强工具：鼠标卡顿、不能全屏、无法传文件
4. 虚拟硬盘放C盘：C盘容易爆满，建议放到D/E盘剩余空间大的分区
5. 测试病毒不要用桥接模式，防止病毒扩散到局域网设备

# 七、总结
虚拟机本质是软件模拟的独立电脑，核心价值：**隔离环境、多系统、安全测试、低成本学习**。
新手路线：开启虚拟化 → 装VirtualBox → 装Windows虚拟机练基础操作 → 玩快照/共享文件夹 → 再学习Linux虚拟机，一周就能熟练日常使用。
