# Redis 完整入门：是什么、能干什么、怎么学
## 一、什么是 Redis
Redis（Remote Dictionary Server，远程字典服务）是一款**开源、内存型 NoSQL 数据库**，用 C 语言开发。
### 核心特点
1. **数据放内存**：读写速度极快，万级 QPS，远快于 MySQL；
2. **多数据结构**：不只是简单 key-value，支持字符串、列表、哈希、集合、有序集合等；
3. **持久化**：内存数据可落地磁盘（RDB/AOF），重启不丢数据；
4. **高可用**：主从复制、哨兵、集群，支持分布式部署；
5. **单线程模型**：核心命令串行执行，无锁竞争，性能高；
6. **支持发布订阅、事务、Lua 脚本、过期淘汰**。

### 和 MySQL 的区别
- MySQL：磁盘关系型数据库，持久化优先，适合存业务原始数据；
- Redis：内存缓存数据库，性能优先，适合热点数据加速、中间件能力。

## 二、Redis 常见用途（工作最常用场景）
### 1. 热点数据缓存（最主流）
减轻数据库压力：商品详情、首页 banner、用户基础信息、配置数据。
流程：查数据先读 Redis，命中直接返回；未命中查 MySQL，再写入 Redis。

### 2. 分布式会话 Session
多台服务器集群时，统一把用户登录信息存在 Redis，实现登录状态共享。

### 3. 计数器 & 限流
- 计数器：文章阅读量、点赞、库存自增减（`INCR`）；
- 接口限流：IP 访问频率控制，防止刷接口。

### 4. 分布式锁
多服务并发修改同一资源（下单扣库存、订单创建），保证原子操作，防止超卖。

### 5. 消息队列（简单版）
- List：简单异步队列，秒杀下单、异步通知；
- Stream：专业消息队列，支持消费组、ack，替代 RabbitMQ 轻量场景。

### 6. 排行榜
有序集合 ZSet：积分排名、销量榜单、热搜排行榜。

### 7. 去重
Set 集合：签到去重、UV 统计、抽奖去重。

### 8. 延时任务
Key 过期监听 / ZSet 延时队列：订单超时取消、短信延迟发送。

## 三、完整学习路线（从零基础到企业实战）
### 阶段1：环境搭建（1天）✅️
1. Windows / Linux / Docker 安装 Redis

   - windows直接去官网下载✅️

   - Linux：yum/apt 一键安装；❌️
   - Docker 一行启动：`docker run -d -p 6379:6379 redis`❌️

2. 基础操作
   - 启动/关闭/连接客户端 redis-cli（在安装目录下）；
   - 修改配置文件 redis.conf（密码、端口、持久化、最大内存）❌️；

3. 可视化工具：Redis Desktop Manager。✅️

### 阶段2：五大基础数据结构（核心，3~5天）
每种结构掌握：适用场景、常用命令、底层简单原理
1. String 字符串：缓存、计数器、分布式ID
   命令：set/get/incr/expire/mset
2. Hash 哈希：存储对象（用户、商品）
   hset/hget/hgetall
3. List 列表：队列、栈、消息队列
   lpush/rpop/lrange
4. Set 集合：去重、交集并集（好友共同关注）
   sadd/smembers/sinter
5. ZSet 有序集合：排行榜、延时队列
   zadd/zrangebyscore/zincrby

**练习建议**：每个结构手写 10 条命令，结合场景举例。

### 阶段3：进阶核心功能（3~4天）
1. 过期策略 & 内存淘汰机制（maxmemory-policy）
2. 持久化：RDB（快照）、AOF（日志）优缺点、配置
3. 事务 MULTI/EXEC/DISCARD，乐观锁 WATCH
4. Lua 脚本：保证多条命令原子执行
5. 发布订阅 pub/sub

### 阶段4：分布式高可用（面试重点，4~6天）
1. 主从复制：一主多从，数据备份、读写分离
2. 哨兵 Sentinel：自动故障转移，主节点宕机自动选新主
3. Redis Cluster 集群（分片）：海量数据扩容，槽位分配 16384
4. 脑裂问题、集群扩容缩容原理

### 阶段5：企业实战场景（重中之重，5天）❌️
结合开发语言实操（Java/Go/Python 任选其一）
1. 通用缓存封装（缓存穿透、击穿、雪崩解决方案）
   - 穿透：布隆过滤器、缓存空值
   - 击穿：互斥锁、热点数据永不过期
   - 雪崩：过期时间随机、集群、多级缓存
2. 分布式锁实现：Redisson（Java）最佳实践
3. 限流：固定窗口、滑动窗口、令牌桶
4. 库存扣减（秒杀系统完整流程）
5. 延时队列（ZSet 实现订单超时）
6. UV、PV 统计，签到系统

**用python连接Redis**✅️

```python
#安装
pip install redis
#第一种方式     默认地址，默认端口
redis_conn = redis.Redis(host='127.0.0.1', port= 6379, db= 0)
#第二种方式
redis_pool = redis.ConnectionPool(host='127.0.0.1', port= 6379, db=0)
redis_conn = redis.Redis(connection_pool= redis_pool)

```

## 六、学习避坑提醒
1. 不要只背命令，**每个命令绑定业务场景记忆**；
2. 不要跳过缓存穿透/击穿/雪崩，面试必考；
3. 生产不用原生 SETNX 做分布式锁，要用 Redisson；
4. 集群和持久化是高频面试难点，必须手动搭建实操；
5. 多思考一致性问题：Redis 和 MySQL 数据如何同步更新。
