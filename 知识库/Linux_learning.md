## 1. 什么是 Linux
### 1.1 定义
Linux 是一套**免费、开源、多用户、多任务、支持多线程和多CPU**的类 Unix 操作系统内核，由芬兰大学生 Linus Torvalds 在1991年开发。
- **内核（Kernel）**：操作系统最底层核心，负责管理硬件（CPU、内存、磁盘、网卡）、调度进程、分配资源、对接硬件驱动。
- 单独 Linux 内核无法直接使用，厂商/社区在内核基础上搭配软件、桌面、工具链，打包成完整操作系统，称为**Linux发行版（Distribution）**。

### 1.2 开源核心协议：GPL
Linux 基于 GNU GPL 开源协议：
1. 任何人可免费使用、修改、分发源码；
2. 修改后的二次分发产品，必须同步公开修改后的源代码；
3. 禁止闭源私有化捆绑，保障永久免费。

### 1.3 GNU 与 Linux 的关系
完整系统全称是 **GNU/Linux**：
- GNU：自由软件项目，提供命令行工具（ls、cd、vim、gcc）、编译器、Shell、基础系统库；
- Linux：仅操作系统内核；
日常口语简称 Linux。

## 2. Linux 核心组成
1. **Linux 内核**：硬件资源调度核心
2. Shell（命令解释器）：用户和内核交互桥梁
   - bash（最通用）、zsh、sh、csh
3. GNU 工具集：基础命令、文件操作、编译工具
4. 文件系统：ext4、xfs、btrfs、tmpfs 等，管理磁盘文件
5. 图形桌面（可选）：GNOME、KDE、Xfce、LXDE（服务器一般不装桌面）
6. 应用程序：服务、开发工具、数据库、中间件

### 核心特性
- 多用户：同时多个账号登录，权限隔离
- 多任务：后台并发运行程序
- 稳定低负载：服务器常年运行不关机，极少蓝屏崩溃
- 权限严格：文件/进程分级权限，病毒极难破坏系统
- 跨硬件：支持x86、ARM、RISC-V、嵌入式芯片、服务器、手机

## 3. Linux vs Windows vs MacOS
|对比维度|Linux|Windows|MacOS|
| ---- | ---- | ---- | ---- |
|开源协议|完全开源免费|闭源商业收费|内核Darwin开源，上层桌面闭源|
|使用场景|服务器、开发、嵌入式、云计算|个人办公、游戏、商用软件|设计师、轻度开发|
|权限机制|严格用户/组/文件权限|管理员/普通用户，权限宽松|类Unix权限，限制修改系统文件|
|资源占用|极简，无后台冗余进程|后台占用高|中等占用，优化较好|
|病毒风险|极低，权限隔离阻断病毒|病毒、木马高发|少量恶意程序|
|软件生态|命令行工具、开源服务为主|桌面商业软件、游戏完善|设计软件、原生开发工具完善|
|商业化授权|免费，企业仅付技术服务费|系统授权、服务器授权收费|设备绑定付费|

## 4. Linux 有什么用（全场景细分）
### 4.1 服务器领域（最主流）
全球 90% 以上服务器、云服务器（阿里云/腾讯云/AWS）使用 Linux：
1. Web服务器：Nginx、Apache 部署网站、小程序后端；
2. 数据库服务器：MySQL、Redis、PostgreSQL、MongoDB；
3. 中间件服务：Docker、K8s、RabbitMQ、Elasticsearch；
4. 云原生、容器集群、微服务平台；
5. 域名DNS、FTP、文件存储、代理服务器。

### 4.2 软件开发环境
后端、大数据、AI 开发首选系统：
1. Python/Java/Go/C++ 编译运行环境；
2. Git、Jenkins CI/CD 自动化部署；
3. 大数据：Hadoop、Spark、Flink 仅原生支持 Linux；
4. AI深度学习：PyTorch、TensorFlow、GPU 算力集群；
5. 嵌入式开发、交叉编译环境。

### 4.3 云计算 & 容器
Docker、Kubernetes 底层强制依赖 Linux，所有云主机、容器、Serverless 底层均为 Linux。

### 4.4 嵌入式设备（随处可见）
1. 手机：Android 内核基于 Linux；
2. 路由器、智能家居、摄像头、电视盒子；
3. 工控机、自动驾驶车载系统、单片机开发板（树莓派）。

### 4.5 个人桌面系统
替代 Windows，适合程序员、极简办公：Ubuntu、Fedora、Deepin，办公、写代码、浏览网页。

### 4.6 超级计算机
全球 TOP500 超算 100% 运行 Linux，科研、气象、仿真、算力计算专用。

### 4.7 网络安全 & 渗透测试
渗透系统 Kali Linux、漏洞扫描、流量抓包、防火墙运维、攻防靶场全部基于 Linux。

## 5. Linux 主流发行版介绍与选择
### 5.1 Debian 系（稳定，新手推荐）
1. **Ubuntu**
   - 优点：文档最全、社区庞大、软件多、上手简单；
   - 适用：个人桌面、新手学习、云服务器、开发机；
2. **Debian**
   - 极致稳定，软件版本保守；适合生产服务器；
3. **Deepin（深度）**
   - 国产发行版，中文桌面美观，适合纯国内用户；
4. Kali Linux
   - 预装渗透工具，网络安全专用。

### 5.2 RedHat 系（企业服务器主流）
1. **CentOS（已停更）**
   - 免费开源RHEL复刻，过去国内服务器标配；
2. **Rocky Linux / AlmaLinux**
   - CentOS替代，企业生产稳定服务器首选；
3. RHEL（RedHat Enterprise Linux）
   - 商业付费，大厂企业服务器；
4. Fedora
   - RedHat测试版，软件最新，适合尝鲜、开发。

### 5.3 其他小众发行版
- Arch Linux：滚动更新，软件最新，适合进阶玩家；
- OpenSUSE：德国发行版，企业稳定分支Leap；
- Alpine Linux：极小镜像，Docker容器专用。

### 新手学习推荐
- 初学练习：Ubuntu 22.04 / 24.04
- 模拟企业服务器：Rocky Linux 9
- 容器学习：Alpine

## 6. 零基础完整学习路线（分四大阶段）
### 阶段1：Linux 基础入门（1~2周）
目标：看懂命令，独立操作文件、账户、权限，理解系统基础逻辑
学习内容：
1. 系统安装（虚拟机/云服务器/WSL）；
2. 终端、Shell基础操作；
3. 文件系统结构 `/etc /home /usr /var /tmp` 目录含义；
4. 基础高频命令：cd ls pwd mkdir rm cp mv cat less grep find；
5. 文件权限 rwx、chmod、chown、用户与用户组；
6. 用户管理 useradd userdel passwd groupadd；
7. 进程基础 ps top kill；
8. 软件安装 apt / dnf；
9. 开关机、运行级别、systemd 基础。

### 阶段2：Linux 服务与运维进阶（2~4周）
目标：独立搭建、管理服务器各类服务
1. 磁盘管理：df du fdisk mount swap 分区挂载；
2. 网络管理：ip addr ping netstat ss firewall防火墙；
3. 文本编辑器 vim 全套操作；
4. 系统日志 /var/log 日志排查；
5. 定时任务 crontab；
6. 远程连接 SSH、免密登录；
7. Web服务 Nginx/Apache 安装配置；
8. MySQL、Redis 基础部署；
9. 文件传输 scp rsync；
10. 系统监控、故障排查思路。

### 阶段3：Shell 脚本编程（2周）
目标：自动化运维，批量处理服务器任务
1. 变量、循环 for/while、判断 if；
2. 函数、数组、字符串处理；
3. 正则表达式；
4. 脚本实操：日志清理、备份脚本、监控告警脚本。

### 阶段4：云原生 & 企业实战（长期进阶）
1. Git 版本控制；
2. Docker 容器、镜像、仓库；
3. Kubernetes K8s 集群；
4. CI/CD Jenkins；
5. 负载均衡、集群、高可用；
6. 大数据/AI Linux 环境部署；
7. 安全加固、服务器攻防基础。

## 7. 环境搭建三种方案（新手优先选WSL）
### 方案1：Windows WSL（推荐零基础，无需虚拟机）
Windows10/11自带Linux子系统，轻量无性能损耗
1. 开启开发者模式，安装WSL2；
2. Microsoft商店安装Ubuntu；
3. 直接在Windows终端运行Linux命令，文件互通。

### 方案2：虚拟机 VMware / VirtualBox
适合完整体验独立Linux系统，支持桌面图形界面
1. 下载Ubuntu镜像ISO；
2. 虚拟机分配2核4G内存、50G硬盘；
3. 完整独立系统，可随意操作、快照备份。

### 方案3：云服务器（阿里云/腾讯云学生机）
模拟真实线上服务器，无图形桌面，纯命令行，贴合运维工作
优势：学习SSH远程连接、公网服务部署，贴近企业真实场景。

### 方案4：实体机安装Linux
淘汰旧电脑直接装Ubuntu，适合长期重度使用。

## 8. 分阶段实操清单（必须动手，只看不学没用）
### 入门实操
1. 安装Ubuntu，熟悉终端；
2. 目录跳转、创建删除文件、批量查找文件；
3. 创建多用户，修改文件权限，测试权限隔离；
4. 使用apt安装卸载软件；
5. 使用top查看进程，杀死异常进程。

### 进阶运维实操
1. 手动挂载U盘/新增磁盘分区；
2. 配置静态IP、防火墙放行端口；
3. SSH免密登录两台服务器互相传输文件；
4. 搭建Nginx静态网站，访问公网页面；
5. 编写定时任务，每天自动备份文件。

### Shell脚本实操
1. 批量创建10个用户脚本；
2. 日志自动清理脚本；
3. 服务器内存、磁盘使用率监控脚本。

### 企业实战项目
1. 搭建LNMP网站环境（Linux+Nginx+MySQL+PHP）；
2. Docker部署前后端项目；
3. 搭建私有Git服务；
4. 定时数据库自动备份。

## 10. 学习避坑指南
1. **不要只看视频不敲命令**：Linux是实操技术，光看永远不会；
2. 新手不要直接使用root最高权限操作，养成普通用户sudo习惯；
3. 不要死记命令，理解参数含义，多用 `man xxx` / `xxx --help` 查帮助；
4. 不要跳过Shell脚本，自动化是运维核心竞争力；
5. 不要长期只用桌面Linux，多练纯命令行服务器模式；
6. 遇到报错优先看系统日志 `/var/log`，不要直接复制提问；
7. 区分发行版命令：apt（Ubuntu）、dnf/yum（Rocky/CentOS），不要混用。

## 11. 学习周期规划参考
1. 一周：熟练基础文件、用户、权限命令；
2. 两周：掌握网络、磁盘、Nginx、定时任务；
3. 一个月：独立完成Shell脚本编写；
4. 两个月：能独立搭建、维护线上Linux服务器；
5. 3~6个月：掌握Docker/K8s，具备初级运维/后端开发环境部署能力。
