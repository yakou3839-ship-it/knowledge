# GitHub SSH 免密登录完整教程（Windows / Mac / Linux 通用）
## 原理
生成一对密钥：**私钥（本地保管，绝不外传）** + **公钥（放到GitHub账号）**
本地push/clone时自动配对验证，不用输入账号密码。

# 1. 本地生成 SSH Key
打开 **Git Bash（Windows推荐）/终端(Mac/Linux)**
执行命令，邮箱填你**注册GitHub的邮箱**
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```
> ⚠️ 如果系统太老不支持ed25519，使用旧算法：
> `ssh-keygen -t rsa -b 4096 -C "your_email@example.com"`

### 交互步骤（重点！全部直接回车，不要设置密码）
```
Enter file in which to save the key (/c/Users/xxx/.ssh/id_ed25519): 【回车】
Enter passphrase (empty for no passphrase): 【回车】
Enter same passphrase again: 【回车】
```
✅ 不设置密码 = 真正免密；如果设置了密码，每次使用ssh都要输密钥密码。

## 2. 找到公钥文件
### Windows 路径
```
C:\Users\你的用户名\.ssh\id_ed25519.pub
```
### Mac/Linux
```
~/.ssh/id_ed25519.pub
```

**打开 .pub 文件，复制全部内容**（以 `ssh-ed25519` 开头，结尾是你的邮箱，**不要漏掉任何字符**）

> 只复制 `.pub`（公钥），**绝对不要上传 id_ed25519 私钥！**

# 3. 把公钥添加到 GitHub
1. 登录 GitHub → 右上角头像 → **Settings**
2. 左侧菜单：**SSH and GPG keys**
3. 右上角 **New SSH key**
4. Title：随便写（例如 `My Windows PC`，区分设备）
5. Key type：`Authentication key`
6. Key 文本框：粘贴刚刚复制的完整公钥
7. Add SSH key，验证GitHub密码

# 4. 测试连接是否成功
终端执行：
```bash
ssh -T git@github.com
```
出现这句代表成功：
```
Hi 你的GitHub用户名! You've successfully authenticated, but GitHub does not provide shell access.
```
> ❗注意：地址固定是 `git@github.com`，**不要换成你的用户名！**

# 5. 修改本地仓库远程地址（关键！HTTPS ↔ SSH 不能混用）
## 查看当前远程地址
```bash
git remote -v
```
如果看到地址是以 `https://` 开头，需要**替换成SSH地址**

### 方式1：直接修改origin地址
```bash
git remote set-url origin git@github.com:用户名/仓库名.git
```

### 方式2：先删除再新增
```bash
git remote remove origin
git remote add origin git@github.com:用户名/仓库名.git
```

> SSH仓库地址格式样板：
> `git@github.com:Jack/test-project.git`

## ✅ 之后clone新项目也要用SSH地址
不要选HTTPS，复制SSH链接：
`git clone git@github.com:用户名/仓库名.git`

# 常见问题排查
## 1）提示 Permission denied (publickey)
1. 确认复制公钥完整，没有换行、空格缺失
2. 确认添加到**个人账号SSH key**，不是仓库内！（很多人踩坑）
3. 检查文件名是否正确：`.pub`公钥

## 2）Windows Git Bash ssh-agent 未启动（偶尔报错）
```bash
# 启动ssh代理
eval "$(ssh-agent -s)"
# 添加私钥
ssh-add ~/.ssh/id_ed25519
```

## 3）一台电脑多个GitHub账号（可选拓展）
需要配置 `~/.ssh/config` 文件区分不同密钥，如果你暂时用不到可以先不学。

# 额外小提示
1. **密钥只属于当前电脑**，换新电脑必须重新生成上传公钥
2. 私钥泄露 = 别人可以操作你所有仓库，妥善保管
3. 之前用HTTPS缓存了账号信息冲突：
```bash
git credential reject https://github.com
```
