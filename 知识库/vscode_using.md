# VSCode 从下载到跑通程序完整教程
VSCode 本质是**通用代码编辑器**，本身不能直接运行代码，完整跑通程序需要三个核心环节：
1. 安装 VSCode 本体
2. 安装对应编程语言的**运行环境**（解释器/编译器）
3. 安装对应语言扩展，编写并运行代码

下面以最通用的 **Python** 为例全程演示，最后补充其他主流语言的配置方法。

---

## 一、下载并安装 VSCode
### 1. 官方下载
打开 VSCode 官网：https://code.visualstudio.com/
网站会自动识别你的操作系统，点击中央蓝色下载按钮即可：
- Windows：推荐 **User Installer（用户安装版）**，无需管理员权限，普通用户直接使用
- macOS：下载 `.dmg` 安装包，拖拽到应用程序即可
- Linux：下载对应发行版的 `deb` / `rpm` 包安装

### 2. Windows 安装详细步骤
1. 双击下载好的安装包，同意许可协议后点击「下一步」
2. 选择安装路径（默认C盘即可，**路径不要有中文和空格**），点击「下一步」
3. 到「选择其他任务」页面，**建议全部勾选**，尤其这几个关键选项：
   - ✅ 添加到 PATH（重启后生效）：可以在命令行直接用 `code` 命令打开文件
   - ✅ 创建桌面快捷方式
   - ✅ 添加“通过 Code 打开”右键菜单
4. 点击「安装」，等待完成后启动 VSCode

### 3. 验证安装
按下 `Win + R` 输入 `cmd` 打开命令提示符，输入：
```
code --version
```
如果输出版本号信息，说明安装和系统环境变量配置成功。

## 二、基础设置：汉化中文界面
1. 打开 VSCode，点击左侧边栏的「扩展」图标（四个方块，快捷键 `Ctrl+Shift+X`）
2. 搜索框输入 `Chinese (Simplified)`
3. 找到微软官方的「中文 (简体) 语言包」，点击「安装」
4. 安装完成后右下角弹出提示，点击「重启（Restart）」，重启后即为全中文界面

## 三、配置 Python 运行环境（核心）
### 1. 安装 Python 解释器（必装前提）
VSCode 本身不带 Python 运行能力，必须先在系统里安装 Python 解释器：
1. 打开 Python 官网：https://www.python.org/downloads/
2. 点击黄色按钮下载最新稳定版（如 Python 3.12.x）
3. **最关键一步**：打开安装包后，**务必勾选最底部的 `Add Python.exe to PATH`**，新手90%的报错都来自没勾选这一项。
4. 点击「Install Now」默认安装（也可自定义路径，同样不要中文）
5. 验证安装：
   打开 cmd 命令提示符，输入：
   ```
   python --version
   ```
   Win11 若弹出应用商店，换成 `py --version` 即可。
   能输出版本号（如 `Python 3.12.4`）就说明安装成功。

### 2. VSCode 安装 Python 扩展
1. 回到 VSCode 扩展商店（`Ctrl+Shift+X`）
2. 搜索 `Python`，找到微软官方出品的「Python」扩展，点击安装
3. 该扩展提供代码补全、语法高亮、运行、调试等全套功能，安装完成后无需重启即可生效。

## 四、编写并运行第一个 Python 程序
### 1. 创建工作文件夹
**非常重要**：VSCode 基于「文件夹」工作，不要单独打开单个文件，否则很多功能异常。
在电脑非中文路径下新建文件夹，例如 `D:\code\python-demo`（全程英文，不要空格和特殊符号）。

### 2. 在 VSCode 中打开文件夹
1. 左上角点击「文件」→「打开文件夹」
2. 选择刚才创建的 `python-demo` 文件夹
3. 弹出信任提示时，**勾选「信任此文件夹中所有文件的作者」**，点击「是，我信任此作者」。不信任会导致扩展和运行功能被禁用。

### 3. 新建代码文件
1. 左侧资源管理器（快捷键 `Ctrl+Shift+E`）中，点击「新建文件」图标
2. 文件名输入 `hello.py`（**后缀必须是 `.py`**，VSCode 靠文件后缀识别语言）
3. 回车确认，文件创建完成。

### 4. 确认 Python 解释器
第一次使用时，VSCode 右下角会显示当前选中的 Python 版本，如果显示不对或为空：
- 按下 `Ctrl+Shift+P` 打开命令面板
- 输入 `Python: Select Interpreter` 并回车
- 在列表里选择你刚才安装的 Python 版本（如 `Python 3.12.4 64-bit`）

### 5. 编写代码
在编辑区输入代码：
```python
print("Hello, VSCode! 我的第一个程序跑通了")
```

### 6. 运行程序（3种常用方法）
- **方法1（最推荐）**：点击编辑区右上角的绿色三角形 ▶️ 按钮，选择「运行 Python 文件」，下方终端会直接输出结果。
- **方法2**：在代码编辑区空白处右键，选择「在终端中运行 Python 文件」。
- **方法3**：按下 `Ctrl + ``（Tab键上方的反引号）打开内置终端，手动输入命令回车：
  ```
  python hello.py
  ```

看到终端输出 `Hello, VSCode! 我的第一个程序跑通了`，就代表环境完全配置成功。

## 五、其他主流语言的配置思路
核心逻辑一致：**先装运行环境 → 再装对应扩展**

### 1. C# 开发
- 先安装 .NET SDK：微软官网下载 .NET 8/9 SDK
- VSCode 安装 `C# Dev Kit` 扩展（微软官方）
- 终端输入 `dotnet new console -n MyApp` 创建控制台项目，打开项目文件夹后点击运行即可

### 2. C/C++ 开发
- 先装编译器：Windows 装 MinGW-w64，macOS 装 Xcode 命令行工具，Linux 装 gcc/g++
- VSCode 安装 `C/C++ Extension Pack` 扩展包
- 需要配置 `tasks.json`（编译）和 `launch.json`（调试），适合有一定基础后使用

### 3. 前端（HTML/CSS/JavaScript）
- 浏览器原生支持运行，无需额外环境
- 推荐安装 `Live Server` 扩展
- 新建 `.html` 文件，右键选择「Open with Live Server」，自动在浏览器打开并实时刷新

### 4. Java 开发
- 先安装 JDK（推荐 JDK17/21），配置 `JAVA_HOME` 环境变量
- VSCode 安装 `Extension Pack for Java` 官方扩展包
- 创建 Java 项目后即可运行

## 六、新手必备插件推荐
在扩展商店搜索名称安装，大幅提升开发体验：
- **Prettier - Code formatter**：统一代码格式化风格，支持绝大多数语言
- **Path Intellisense**：文件路径自动补全，写导入路径更高效
- **Code Spell Checker**：代码单词拼写检查，避免变量名拼错
- **One Dark Pro**：主流深色代码主题，护眼美观
- **Git Graph**：Git 提交历史可视化，比命令行更直观

## 七、常见问题排查
1. **提示“python 不是内部或外部命令”**
   99% 是安装 Python 时没勾选「Add to PATH」，重装 Python 并勾选对应选项即可解决。

2. **运行报错、乱码、找不到文件**
   检查文件夹路径、文件名是否包含**中文、空格、特殊符号**，改成纯英文路径可解决绝大多数新手问题。

3. **右上角没有运行按钮**
   检查文件后缀是否正确（比如 Python 必须是 `.py`），以及对应语言的扩展是否安装成功。

4. **扩展不生效、功能缺失**
   不要单独打开单个文件，必须用「打开文件夹」的方式打开代码目录，并且信任工作区。
