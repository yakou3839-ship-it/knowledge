### 术语解释
- **Ollama**: 一款专为本地运行和管理大模型设计的开源工具，简化了模型下载、部署和交互的流程。
- **Llama 3**: 由 Meta 公司开发的开源大模型系列，以强大的逻辑推理和生成能力著称，是目前本地部署的主流选择之一。
- **Docker**: 一个开源的容器平台，能够将应用程序及其依赖环境“打包”，确保软件在任何计算机上都能以相同的方式运行。
- **Open WebUI**: 一个基于 Web 的大模型交互界面，旨在为 Ollama 等后端提供类似于 ChatGPT 的可视化操作体验。

## 视频章节总结 ｜ 📥「欧拉玛」工具：一键部署开源大模型！

该文指导如何下载欧拉玛工具并部署开源大模型。首先，从官网下载适合系统的EulerMa安装包，安装后在命令行输入"oLama run Lama3"运行模型。要尝试其他模型，可在官网找到模型口令，然后用"EulerMa run + 模型名称"命令运行。若想获得更友好的交互界面，可下载OpenWebUI，但需先安装Docker。OpenWebUI启动后，通过localhost 3000访问，支持文件上传和界面语言切换，以便与本地运行的大模型进行交互。

下载欧拉玛工具，快速部署开源大模型。访问官网，点击下载，使用“欧拉玛run”命令即可运行模型。

下载按钮将用户转到选择适合自己系统的下载包页面，例如选择Windows下载。下载完成后，点击刚刚下载的EulerMa，按照安装步骤进行安装。安装完成后，Windows用户可以在电脑底部搜索命令行或按Win+R，在出现的框框内输入cmd并回车。

### [00:54](https://bibigpt.co/content/d80757bc-f391-48df-917a-7fe003e53435?t=54.660) - 下载大模型

该黑框框只是一个可读取和执行输入命令的地方。在终端输入"oLama run Lama3"命令，即让OulaMa运行Lama3模型。此时开始下载Lama3模型，默认下载8B版本，无需显卡即可运行。下载完成后，可直接开始对话。如果愿，还可继续学习，因为操作仍然很简单。

### [01:33](https://bibigpt.co/content/d80757bc-f391-48df-917a-7fe003e53435?t=93.840) - 加载开源大模型

首先，按 Ctrl+D 或回复 "by" 可退出对话。接下来，打开 EulerMa 官网，点击右上角 "models"，可找到各种前沿开源大模型。选择想要的模型，复制其口令，输入 EulerMa run + 模型名称。最近登顶的阿里千问大模型也可以这样获取。但是，终端聊天可能有点原始，因此可下载 OpenWebUI，一个运行在本地的类似 ChatGPT 操作界面。在此之前，需安装 Docker，但无需了解 Docker 的细节，只要知道它简单易用即可。前往 Docker 官网下载。

### [02:30](https://bibigpt.co/content/d80757bc-f391-48df-917a-7fe003e53435?t=150.600) - OpenWebUI

本文介绍了如何在自己的电脑上安装并运行一个大模型，安装完成后通过命令行启动Web UI操作界面，该过程需要下载10G的包，下载成功后会自动打开网页。如果没有自动弹出，可手动输入localhost 3000或在Docker中点击跳转链接。使用时可在网页链接前加井号读取链接，点击左边加号上传文件。通过设置可将界面改为中文，并设定提示词让模型永远回复中文。这样就可以随时访问运行在自己电脑上的大模型。
