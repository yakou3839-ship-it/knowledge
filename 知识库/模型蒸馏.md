# 模型蒸馏（知识蒸馏 Knowledge Distillation, KD）

模型蒸馏是**模型压缩、知识迁移**的经典技术，由 Hinton 2015 年提出，核心范式：**大的教师模型教小的学生模型**。

> 通俗比喻：博学但笨重的老教授（大教师模型），不直接把大脑复制给学生；而是把自己的思考、判断逻辑讲出来，让年轻、脑子小但反应快的学生（小模型）学会这套思路，学生独立上岗工作。

## 核心概念

1. **教师模型 Teacher** 已经训练完成、参数量大、精度高，但推理慢、吃显存 / GPU，**蒸馏阶段参数冻结，只做推理输出，不更新权重**。
2. **学生模型 Student** 结构简单、参数量小，推理快、内存占用低；训练阶段去模仿教师，训练完脱离教师独立部署。
3. **硬标签 Hard Label** 传统训练用：只有标准答案，例如图片是猫，标签就是`猫=1，其他类别=0`，只告诉它最终答案。
4. **软标签 Soft Label（暗知识 Dark Knowledge）** 教师输出带温度系数 T 软化后的概率分布。 例：输入一张图片，教师输出：猫 0.85、老虎 0.12、狐狸 0.03。

> 它不仅告诉你 “这是猫”，还告诉你：教师认为这张图**有点像老虎**，传递类别之间相似关系、模型的思考偏好，这就是大模型学到的隐性暗知识。

## 蒸馏完整流程

1. 提前训练好高性能的**教师大模型**，训练完成不再改动。
2. 输入同样一批数据，过教师模型，生成**软标签（软化概率）**。
3. 训练学生模型，损失函数由两部分加权组合：
   - 蒸馏损失：学生输出尽量拟合教师输出的**软标签**
   - 真实任务损失：学生拟合原始数据集的**硬标签**
4. 训练结束丢掉教师模型，只保留学生模型上线部署。

> 温度系数 T：T 越大，概率分布越平滑，放大次要类别的差异，方便学生学到类别之间的关系；推理时 T 重置为 1。

## 蒸馏的 3 种主流类型

1. **输出层蒸馏（Logits 蒸馏，经典）**：对齐教师和学生最后的输出概率，最简单，如 DistilBERT。
2. **特征 / 隐层蒸馏**：不光学输出，还对齐网络中间层、Attention 注意力矩阵，学生模仿教师内部的特征表达，效果更好，开销更大（TinyBERT）。
3. **关系蒸馏**：学习样本与样本、层与层之间的关联结构。

## 典型案例

- DistilBERT：BERT 蒸馏而来，参数减少 40%，速度提升 60%，保留 97% 能力。
- TinyBERT：BERT 蒸馏，同时蒸馏 Attention 与隐层表示。
- 大模型场景：千亿大模型蒸馏出 7B/13B 小模型，用于本地、边缘部署。



## 蒸馏的三种管道

**白盒蒸馏：**拿到老师本体，抛开脑壳直接看每个词的概率分布，让学生模型逐词对齐，通常发生在自家模型之间。（这个一般需要拿到教师模型的本体）

**黑盒蒸馏：**拿不到教师模型的本体，就疯狂提问，把教师的回答攒成教材微调学生，新闻（说kimi蒸馏claude）中说的就是这个。有个缺点，学生训练时看的全是老师的完美范文，真上考场，面对的却是自己的错误。

**在线蒸馏（仅两年主线）：**学生自己学作业，老师逐句批改。

## 蒸馏 vs 其他压缩手段

表格

| 技术     | 原理                     | 特点                                       |
| -------- | ------------------------ | ------------------------------------------ |
| 知识蒸馏 | 大模型教小模型，迁移知识 | 可以跨网络结构；训练阶段需要大模型参与推理 |
| 模型剪枝 | 直接删除网络不重要权重   | 只能基于原模型结构裁剪                     |
| 模型量化 | 降低参数存储比特位数     | 不改变网络结构，只是数值压缩               |

## 优缺点

✅ 优点

1. 小模型获得远超直接训练的效果，推理速度快、显存占用低，适合手机、边缘设备、高并发线上服务。
2. 可以跨架构迁移知识，教师学生网络结构可以完全不一样。
3. 有正则化效果，一定程度抑制过拟合。

❌ 缺点

1. **上限受教师限制**：教师差，学生一定差；很难 100% 追上教师性能，复杂推理任务损失更明显。
2. 会继承教师模型的偏见、错误。
3. 需要消耗算力跑教师做蒸馏训练，调参复杂（温度 T、损失权重）。
4. 罕见边角案例容易丢失能力。

## 应用场景

- NLP：聊天机器人、翻译、文本理解，把大模型蒸馏为线上服务小模型。
- CV：移动端图像识别、目标检测。
- 边缘 / 端侧 AI：手机、嵌入式设备本地跑 AI 模型。
- 线上高并发业务：大量请求，用蒸馏小模型降低 GPU 成本。
