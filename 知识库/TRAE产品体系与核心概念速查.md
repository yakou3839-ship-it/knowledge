# TRAE 产品体系与核心概念速查

> 整理时间：2026-06-29
> 适用范围：TRAE 国内版（trae.cn）及相关产品

---

## 一、TRAE 产品家族总览

TRAE 是字节跳动旗下的 AI 原生开发与工作品牌，目前包含四条产品线：

| 产品 | 定位 | 形态 | 核心用途 |
|---|---|---|---|
| **TRAE IDE** | AI 原生集成开发环境 | Windows/macOS/Linux 桌面端 | 专业编程、调试、项目管理 |
| **TRAE Work** | AI 原生工作空间 | Web、桌面端、移动端 | 广义工作场景（文档、数据、演示、编程） |
| **TRAE CLI** | 命令行 AI 编码代理 | 终端工具 | 命令行场景下的 AI 辅助开发 |
| **TRAE Plugin** | AI 助手插件 | VS Code / JetBrains 扩展 | 为现有 IDE 增加 TRAE AI 能力 |

> **命名提示**：TRAE Work 此前曾称作 TRAE SOLO，部分旧文档或界面中可能仍保留 SOLO 字样。

---

## 二、版本区分：国内版 vs 国际版

TRAE IDE 和 TRAE Work 均分为国内版与国际版，核心差异如下：

| 维度 | 国内版（CN） | 国际版 |
|---|---|---|
| **官网** | trae.cn / trae.com.cn | trae.ai |
| **服务器** | 国内，直连免翻墙 | 海外节点，需国际网络环境 |
| **登录方式** | 手机号、掘金账号 | 邮箱、Google、GitHub |
| **核心模型** | 豆包、DeepSeek、GLM、Kimi 等国产模型 | GPT-4o、Claude、Gemini 等国际模型 |
| **付费策略** | 内置国产模型免费使用 | 基础版免费，高级模型需 Pro 订阅 |
| **Builder 阶段** | Alpha | Beta |

**建议**：国内开发者优先使用国内版，网络稳定且免费；如需国际模型再考虑国际版。

## 三、TRAE Work 的工作模式

TRAE Work 采用 **Work + Code 双模式** 设计，根据任务类型灵活切换：

| 模式 | 面向场景 | 典型任务 |
|---|---|---|
| **Work 模式** | 广义工作场景 | 撰写文档、数据分析、整理资料、制作演示、跨设备任务编排 |
| **Code 模式** | 专业编程场景 | 代码生成与修改、调试排错、仓库管理、Git 工作流 |

**平台优势**：TRAE Work 支持 Web、桌面端、移动端，可随时随地处理工作事务，不限于编程。

## 四、TRAE IDE 的工作模式

TRAE IDE 是桌面端软件，左上角可切换两种工作界面：

| 模式 | 主导方式 | 界面特点 | 适用场景 |
|---|---|---|---|
| **IDE 模式（默认）** | 人主导，AI 辅助 | 传统 IDE：编辑器 + 文件树 + 终端 + 侧边栏 | 日常编码、调试、查看代码、逐步迭代 |
| **SOLO 模式** | AI 主导，自动推进 | 三栏布局：任务管理 + 对话面板 + 工具面板 | 复杂项目开发、架构重构、从 0 到 1 全自动实现 |

### 4.1 IDE 模式下的智能体

在 IDE 模式中，右侧边栏可使用不同类型的智能体：

| 智能体 | 特点 | 适用场景 |
|---|---|---|
| **Chat** | 快速响应技术问答 | 咨询、解答、代码解释 |
| **Agent** | 调用工具逐步交互，从 0 到 1 开发 | 中小型项目、功能模块搭建 |
| **SOLO Agent** | 自动规划并执行，支持多任务并行与多智能体协同 | 复杂项目、多模块并行迭代 |

> **关键区别**：SOLO 模式与 SOLO Agent 是配套关系——进入 SOLO 模式后，默认使用 SOLO Agent 进行复杂项目的自动化开发。

## 五、核心概念对比总表

### 5.1 TRAE Work Code 模式 vs TRAE IDE

| 维度 | TRAE Work Code 模式 | TRAE IDE |
|---|---|---|
| **产品形态** | 工作空间中的模式选项 | 独立桌面软件 |
| **交互方式** | 对话 + Agent 指令驱动 | 传统 IDE 界面，AI 嵌入编码流程 |
| **代码编辑器** | 无传统编辑器，AI 生成和修改文件 | 内置完整编辑器，支持高亮、提示、多光标 |
| **终端/调试** | 依赖 MCP 或外部工具 | 内置终端、调试器、版本控制面板 |
| **平台** | Web / 桌面 / 移动端 | 桌面端（Windows/macOS/Linux） |
| **适用场景** | 跨设备轻量开发、快速原型 | 本地大型项目、深度调试、复杂工程管理 |

### 5.2 SOLO 模式 vs IDE 模式（均属于 TRAE IDE）

| 维度 | IDE 模式 | SOLO 模式 |
|---|---|---|
| **界面** | 编辑器 + 文件树 + 终端 | 任务管理 + 对话 + 工具面板 |
| **推进方式** | 逐步交互，人工确认 | 确认计划后自动推进 |
| **任务管理** | 单任务串行 | 多任务并行 |
| **智能体** | Chat / Agent | SOLO Agent（可编排多智能体协同） |
| **适用场景** | 日常编码、逐步迭代 | 复杂项目、架构重构、全自动实现 |

## 六、使用场景快速决策

| 你的需求 | 推荐选择 |
|---|---|
| 手机/平板上处理工作事务 | TRAE Work（Work 模式） |
| 跨设备快速写代码、做原型 | TRAE Work（Code 模式） |
| 本地专业开发，需要完整 IDE 环境 | TRAE IDE（IDE 模式） |
| 让 AI 自动完成复杂项目或架构重构 | TRAE IDE（SOLO 模式） |
| 在 VS Code / JetBrains 中使用 TRAE AI | TRAE Plugin |
| 命令行场景下的 AI 辅助 | TRAE CLI |

## 七、关键概念速记

- **TRAE CN** = TRAE 国内版（trae.cn），与国际版（trae.ai）相对
- **TRAE Work** = AI 工作空间，原称 SOLO，支持 Work + Code 双模式
- **TRAE IDE** = AI 原生 IDE，支持 IDE 模式 + SOLO 模式
- **Code 模式** = TRAE Work 中的编程专用模式
- **SOLO 模式** = TRAE IDE 中的 AI 主导自动化开发界面
- **Agent** = IDE 模式中的逐步交互开发智能体
- **SOLO Agent** = SOLO 模式中的自动推进智能体，支持多任务、多智能体协同
